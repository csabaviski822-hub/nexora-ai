# NEXORA AI — induló weboldalcsomag

Ez egy statikus, reszponzív magyar nyelvű kezdőoldal és mintacikk.

## Fájlok
- `index.html` — főoldal
- `styles.css` — megjelenés
- `articles/mi-az-a-mesterseges-intelligencia.html` — mintacikk
- `about.html`, `privacy.html`, `disclosure.html` — kitöltendő oldalak
- `assets/favicon.svg` — ikon

## Fontos indulás előtt
1. A NEXORA AI csak munkanév; ellenőrizd a domain- és védjegyelérhetőséget.
2. Cseréld le a mintaszövegeket, és publikálás előtt ellenőrizd a cikkek tényállításait, forrásait.
3. A hírlevél űrlap jelenleg csak látványelem, nem tárol e-mail-címet.
4. Az adatvédelmi és jogi oldalak nem kész jogi dokumentumok; töltsd ki a tényleges üzemeltetői/adatkezelési adatokkal.
5. Analitika és hirdetési kód nincs bekötve. Hozzáadásuk előtt állíts be megfelelő hozzájárulás-kezelést.
6. AdSense vagy affiliate programhoz csak a szolgáltató aktuális feltételeinek teljesítése után jelentkezz.

## Ingyenes közzététel
A csomag statikus HTML/CSS/JS oldal. Például Cloudflare Pages-re vagy GitHub Pages-re feltölthető. A szolgáltató fiókjában a közzététel lépéseit végig kell kattintani; ezt a csomag önmagában nem végzi el.
